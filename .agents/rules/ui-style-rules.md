# Правила визуального интерфейса TechGear (ui-style-rules.md)

Данный документ содержит ключевые требования и стандарты оформления визуального интерфейса для ИИ-агентов и разработчиков при создании или изменении страниц и компонентов проекта **TechGear**.

---

## 🎨 Стандарты дизайна и верстки

1. **Единый источник истины:**
   * Любые работы по верстке, стилизации и созданию интерфейса должны строго следовать спецификации [`Design.md`](file:///c:/Users/User/Desktop/internetMagazine_AI/Design.md).
   * Запрещено самовольно изменять дизайн-систему, добавлять несогласованные цвета, шрифты или стили скруглений.

2. **Цветовая палитра:**
   * Использовать только зафиксированные дизайн-токены:
     * `primary` (`#0F172A`, Deep Graphite) — для текстов и заголовков;
     * `secondary` (`#475569`, Cool Slate) — для второстепенной информации;
     * `accent` (`#06B6D4`, Electric Cyan) — для фокуса, активных вкладок и акцентов бренда;
     * `cta` (`#F59E0B`, Vibrant Amber) — для кнопок покупки и оформления заказа;
     * `page-bg` (`#F8FAFC`) — фон подложки;
     * `neutral-bg` (`#FFFFFF`) — фон карточек и контейнеров.
   * Статусы наличия и заказов должны оформляться с мягким цветным фоном (`-bg`) и контрастным текстом (Emerald, Rose, Amber, Blue).

3. **Типографика:**
   * Шрифт по умолчанию — **Inter** (для заголовков `h1`–`h3`, описаний, форм и кнопок).
   * Моноширинный шрифт — **Geist Mono** или **JetBrains Mono** — применяется строго для вывода цен, технических параметров (DPI, частота и т.д.), артикулов и таблиц характеристик.

4. **Сетка и отступы (Spacing):**
   * Все внутренние и внешние отступы должны строго соответствовать шкале отступов: `xs` (4px), `sm` (8px), `md` (16px), `lg` (24px), `xl` (32px), `2xl` (48px), `3xl` (64px).

5. **Скругления углов (Rounded):**
   * Запрещено использовать произвольные значения скруглений. Использовать: `sm` (4px) для чекбоксов/бейджей, `md` (8px) для кнопок/инпутов, `lg` (12px) для карточек товаров/модальных окон, `xl` (16px) для баннеров/корзины, `full` (9999px) для капсул-категорий.

6. **Компоненты интерфейса:**
   * **Карточки товаров:** Должны иметь белый фон, рамку `1px solid {colors.border}`, скругление `12px`, изображение на подложке `#F8FAFC`. На hover — плавно приподниматься на 4px (`translate-y-[-4px]`) с подсветкой рамки цианом.
   * **Кнопки:** Соблюдать стили `Primary` (Slate-900), `Secondary` (Slate-100) и `CTA` (Vibrant Amber).
   * **Состояния:** Элементы обязаны иметь выразительные стили при наведении (`hover`), фокусе ввода (`focus-visible` кольцо циана) и неактивном состоянии (`disabled` 50% непрозрачности).

7. **Адаптивность (Responsive):**
   * Минимальная поддерживаемая ширина — 320px.
   * На мобильных экранах категории должны превращаться в горизонтальный свайп, а блок покупки на странице товара должен закрепляться внизу экрана (`sticky bottom bar`).

8. **Чистота кода:**
   * Использовать переиспользуемые UI-компоненты (библиотека shadcn/ui) вместо дублирования стилей и разметки.
   * Оформление административной панели должно полностью соответствовать стандартам [`Design.md`](file:///c:/Users/User/Desktop/internetMagazine_AI/Design.md) (плоский строгий интерфейс с темным сайдбаром Slate-900 и компактными таблицами).
