# Project Workflow

Перед выполнением задачи:

1. Изучи релевантные документы:
   - docs/TZ.md
   - docs/stack.md
   - docs/Architecture.md
   - Design.md
   - SECURITY.md

2. Проверь существующую реализацию перед изменениями.

3. Не изменяй архитектуру, стек или дизайн-систему
   без явного указания пользователя.

4. Для UI используй Design.md и ui-style-rules.md.

5. Для безопасности используй SECURITY.md
   и security-rules.md.

6. Для Prisma используй соответствующие skills.

7. Перед завершением:
   - typecheck
   - lint
   - tests, если они относятся к изменению
   - build, если изменение может повлиять на сборку.

8. Не создавай лишние файлы и зависимости.

9. Не записывай реальные секреты.

10. После выполнения сообщи:
    - что изменено;
    - какие файлы созданы;
    - какие проверки выполнены;
    - какие проблемы остались.
